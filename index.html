Kanal-Tracker

Ein privates Windows-Programm, mit dem der Betreiber die Statistiken seiner eigenen YouTube-Kanäle an einem Ort sieht: Aufrufe pro Tag, Wiedergabedauer und Zuschauerbindung.

Das Programm liest Daten nur lesend über die offizielle YouTube Analytics API und die YouTube Data API. Es veröffentlicht, ändert oder löscht nichts auf YouTube.

Die Daten bleiben auf dem eigenen Rechner und werden an niemanden weitergegeben.
